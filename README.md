# 网格生产AI助手 H5

手机端初版，登录后进入包含“生产总览”“低产预警监控”“校园生产管理”的工作台。校园生产管理目前仅保留菜单和占位页，不连接校园生产通。指标为放号、119+套餐、终端合约、手宽新增、千兆运营。产能和目标是两种数据源：产能由业务系统返回，目标由市公司导入。每一级产能页都显示目标、差额和完成率；预警页筛选低产/零产人员和渠道，阈值可调整。

## 本地运行

```bash
npm install
npm run dev
```

开发环境默认 `VITE_USE_MOCK=true`，所有数据为演示数据。可用账号：

| 手机号 | 权限 | 起始页 |
| --- | --- | --- |
| 13800000000 | 市公司主管/领导 | 工作台；全市五项指标 → 分公司 → 网格 → 预警；监控可选分公司/网格/产品/阈值 |
| 13800000001 | 城区分公司领导 | 工作台；本公司五项指标 → 网格 → 预警；监控可选本网格/产品/阈值 |

演示环境的“目标值管理”只对市公司账号显示。CSV 模板字段为 `gridId,productId,target,dailyTarget,targetDate`：`target` 为月目标，`dailyTarget` 为独立日目标，`targetDate` 为日目标对应的数据截止日（YYYY-MM-DD）。日目标可留空，此时显示未设目标；旧版三列月目标模板仍可导入，保留已有日目标。必须保留全部网格×产品记录，不允许重复或负数。导入数据保存在当前浏览器的 `localStorage`，不代表真实平台已保存。

界面使用浅蓝绿城市封面：网页加载 `public/images/city-cover-bluegreen.jpg`，高清源图保存在 `design-sources/city-cover-bluegreen-original.png`。导航及产品图标来自 Lucide，许可文件见 `public/icons/LICENSE-LUCIDE.txt`。

## 平台接入

生产总览右上角可筛选“全部类型、三星+渠道、末梢渠道、直销队伍”，所选类型在产能页下钻时保留。数据行新增 `channelType` 字段，取上述三类之一，由业务系统提供正式分类；兼容旧值“3星+渠道”和“末梢”。当前人员分类仅为演示。

预警页不显示生产类型下拉框，使用“直销人员、3星+渠道、末梢渠道”三个标签及对应统计数量：直销按个人产能筛选，两类渠道分别按渠道合计产能筛选；均包含零产与产能小于等于阈值的对象。组织、产品及当日/本月条件共同影响三类统计，总览中的生产类型不会隐式限制预警结果。

预警卡片字段：人员展示姓名、`staffRole`（装维随销/行销经理/商企经理之一）、员工编号及分公司/网格；3星+渠道展示渠道名称、`channelStar`（数值星级）、`channelCode`（文本编码）及分公司/网格；末梢渠道展示 `microChannelName`（小微渠道名称）、`serviceProvider`（区域服务商）及分公司/网格。渠道按网格、渠道编码和类型聚合，兼容缺少编码的旧数据按名称聚合；正式数据应使用唯一渠道编码。缺少字段时显示“未提供”，不从队伍或名称推断正式属性。当前新增属性为演示，后续由人员、渠道对应表关联提供。

“全部类型”使用无 `channelType` 的网格产品目标，显示日/月目标、完成率、差距和进度条。选中三星+渠道、末梢渠道或直销队伍时隐藏目标、完成率及差距文字，保留进度条、日/月产能、日均对比及两点趋势；总览、分公司和网格各层级遵循同一规则。分类进度仍按接口中的同分类目标计算，未提供对应目标时显示空轨道，不借用总目标或伪造完成率。CSV 导入只维护总目标。

## 话术推荐

预警页按所选产品提供可展开的话术推荐，支持复制。初始内容为明确标注的示例，不代表公司最新资费或正式活动政策。市公司账号可维护内容，保存时自动记录更新时间；分公司及网格长仅查看与复制。演示内容保存在当前浏览器的 `localStorage`，同浏览器切换账号可见，其他电脑不会同步。

正式接口 `grid_ai_get_dashboard` 增加 `salesScripts: [{ productId, content, updatedAt, status, source }]`，每个产品返回一份当前有效版本。`grid_ai_save_sales_script` 接收 `{ script: { productId, content } }`；服务端校验会话市公司权限、有效产品及内容长度，写入服务器更新时间，保存到共享存储后返回当前版本。前端传入的角色、日期与状态不能作为授权或审核依据。

## 日月产能与趋势

每个产品、分公司及网格均使用同一套日/月产能展示：日产能匹配截止日的独立日目标，月产能匹配月目标；分别显示完成率、差距和进度条。未提供日目标时不会把月目标自动拆分成正式日目标。

日趋势仅连接两个点：“周日均”和具体数据截止日（YYYY-MM-DD）；月趋势仅连接两个点：“上月同期日均”和“本月日均”。各点直接标注数值。日值较本周日均、以及本月日均较上月同期日均，均显示增减数值与比率；差值为本期减基期，比率为差值除以基期，基期为零且本期非零时比率不适用。本周日均按周一至数据截止日的已过自然日计算，跨月或跨年时需要对应日数据；本月及上月同期日均按各自统计区间自然日数计算。上月同期沿用大小月截断规则。缺失数据标为“—”，不连线；真实零值正常保留。

接口在原 `rows`（当月累计工号数据）之外提供 `dailyRows`：`[{ branchId, gridId, staffId, staffName, team, channel, channelType, productId, date: '2026-10-08', production: 2 }]`。历史至少覆盖完整上月及本月截至统计日的数据，按真实零产记录完整返回；服务端仍须按会话权限裁剪历史。`targets` 可追加 `dailyTarget` 与 `targetDate`，日目标仅在对应截止日生效。区域/渠道的正式数据应分别使用对应取数表口径，当前原型使用演示工号数据汇总。

当前历史曲线与日目标均为模拟数据：每日演示值合计与当月演示产能一致，日目标仅为展示生成；真实接入后必须分别使用系统每日取数及市公司导入目标，不能从月累计值反推出真实每日曲线。

前端接口在 `src/api/production.js`，平台 `handle2` 结构在 `src/api/client.js`。`网格生产AI助手平台接口代码示例.js` 是数据库适配示意，并非可直接上线的后端。

`grid_ai_get_permission` 返回 `{ name, phone, role, cityName?, branchId?, branchName?, gridId?, gridName? }`，`role` 为 `city`、`branch` 或 `grid`。市公司主管/领导映射 `city`；分公司领导/主任映射 `branch` 并绑定所属 `branchId`；网格长映射 `grid` 并绑定所属 `branchId`、`gridId`。

`grid_ai_get_dashboard` 返回：

```json
{
  "organization": { "cityName": "中山市", "branches": [{ "branchId": "B01", "branchName": "城区分公司" }], "grids": [{ "gridId": "G001", "gridName": "城区一网格", "branchId": "B01" }] },
  "statDate": "2026-09-21",
  "periods": { "current": { "startDate": "2026-09-01", "endDate": "2026-09-21" }, "previous": { "startDate": "2026-08-01", "endDate": "2026-08-21" } },
  "products": [{ "productId": "newNumbers", "productName": "放号", "unit": "户" }],
  "targets": [{ "gridId": "G001", "productId": "newNumbers", "target": 62 }],
  "rows": [{ "branchId": "B01", "gridId": "G001", "staffId": "S001", "staffName": "梁敏", "team": "直销一队", "channel": "社区摆摊", "productId": "newNumbers", "production": 15 }]
}
```

“上月同期产能”按数据截止日对齐：若本月最新数据截止到 9 月 18 日，则本期取 9 月 1 日至 9 月 18 日，上月同期取 8 月 1 日至 8 月 18 日。大小月按上月实际天数截断，例如本期截止 10 月 31 日，上月同期取 9 月 1 日至 9 月 30 日；3 月 31 日对应 2 月 28 日或闰年的 2 月 29 日。后端必须使用 `periods` 中的闭区间分别汇总本期和上月同期产能。

`grid_ai_import_targets` 接收 `{ rows: [{ gridId, productId, target }] }`，仅市公司权限可提交。后端应校验全量覆盖、重复项、有效组织/产品、目标数值及统计周期，按周期原子替换或事务更新；建议目标表唯一键为 `period + gridId + productId`。

**权限必须在服务端执行**：根据已认证的会话确认手机号和角色，不信任前端传入的 `phone`、`branchId`、`gridId`；市公司可看全市，分公司只返回本公司数据，网格长只返回本网格数据。产能按同一统计周期累计，目标周期与之匹配。零产分析要求在岗人员×产品的零值记录也能返回，不能只返回有订单的人。演示账号和本地导入逻辑不得作为生产权限或持久化方案。
